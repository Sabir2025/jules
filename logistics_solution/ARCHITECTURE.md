# Архитектура системы автоматизации логистики

Данное решение разработано для автоматизации взаимодействия между логистами (офисными сотрудниками) и водителями большегрузов (полевыми сотрудниками) без использования платного ПО.

## Основные компоненты

1.  **Google Таблицы (CRM и База данных)**
    - Служит основным интерфейсом для логиста.
    - Хранит данные о заказах, водителях, статусах и статистику.
    - Преимущества: бесплатно, не требует установки ПО, знакомый интерфейс, поддержка совместной работы.

2.  **Telegram Bot (Интерфейс водителя)**
    - Единственный инструмент для водителя.
    - Взаимодействие происходит через чат-бот с использованием интерактивных кнопок (минимум ввода текста).
    - Преимущества: бесплатно, работает на любом смартфоне, привычно для пользователей.

3.  **Google Apps Script (Центральный узел / Backend)**
    - Скрипт, привязанный к Google Таблице.
    - Обрабатывает входящие сообщения от Telegram (Webhooks).
    - Отправляет уведомления водителям при назначении заказа в таблице.
    - Обновляет данные в таблице на основе действий водителя.

## Схема работы (Workflow)

1.  **Создание заказа**: Логист вносит данные о рейсе в новую строку Google Таблицы.
2.  **Назначение**: Логист выбирает водителя из выпадающего списка в таблице.
3.  **Уведомление**: Скрипт автоматически обнаруживает назначение и отправляет водителю в Telegram карточку заказа с кнопкой «Принять».
4.  **Выполнение**: Водитель нажимает кнопки в Telegram по мере прохождения этапов:
    - «Прибыл на погрузку»
    - «Погрузка завершена»
    - «В пути»
    - «Прибыл на выгрузку»
    - «Разгружен / Заказ завершен»
5.  **Обновление CRM**: При каждом нажатии кнопки скрипт мгновенно меняет статус и ставит отметку времени в соответствующей ячейке Google Таблицы.
6.  **Контроль**: Логист видит изменения статусов в реальном времени (ячейки могут подсвечиваться разными цветами через условное форматирование).

## Безопасность и масштабируемость

- Доступ к таблице регулируется стандартными средствами Google (по email).
- Регистрация водителей происходит через связку Telegram ID и номера телефона, указанного в таблице.
- Система выдерживает сотни активных заказов одновременно в рамках бесплатных квот Google.
