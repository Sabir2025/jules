# Инструкция по развертыванию MoveX Logistics

Данная система состоит из PWA (веб-приложения) на базе Google Apps Script, Google Таблицы и Telegram бота.

## 1. Настройка Google Таблицы
1. Откройте вашу таблицу: [MoveX Logistics Table](https://docs.google.com/spreadsheets/d/1BT1PrFmpwHqBS5iWfjjryg_VAlvXqLvohxAxu2u2eoo/)
2. Перейдите в **Extensions (Расширения)** -> **Apps Script**.
3. Скопируйте содержимое всех файлов из папки `logistics_solution/src/` в редактор Apps Script (создайте файлы с такими же именами).

## 2. Развертывание (Deploy)
1. В редакторе Apps Script нажмите кнопку **Deploy (Развернуть)** -> **New deployment**.
2. Выберите тип **Web App**.
3. Установите настройки:
   - **Execute as:** Me (Ваш аккаунт)
   - **Who has access:** Anyone (Чтобы водители могли зайти в форму)
4. После деплоя вы получите **Web App URL**.
5. **ВАЖНО:** Скопируйте этот URL и вставьте его в файл `telegram.gs` в функцию `sendToTelegram` (замените текущий URL в кнопке).

## 3. Настройка Telegram Бота
1. Вставьте ваш `Web App URL` как Webhook для бота (необязательно, если не используете входящие команды, но полезно):
   `https://api.telegram.org/bot<TOKEN>/setWebhook?url=<YOUR_WEB_APP_URL>`
2. Добавьте бота в группу водителей и сделайте его администратором.

## 4. Первый запуск
1. В редакторе Apps Script выберите функцию `setupSheets` в файле `setup.gs` и нажмите **Run**. Это создаст необходимые заголовки в таблице.
2. Теперь вы можете открыть **Web App URL** на телефоне и начать работу!

## Основные возможности:
- **Логист:** Регистрация, вход, добавление груза, просмотр своих грузов и статистики.
- **Водитель:** Получает сообщение в группе, нажимает "Взять груз", вводит данные, после чего статус в таблице меняется на "Закрыто".
